Add hairy-tracer-core Rust crate: intersection & AABB (step 1/3)

Standalone Rust crate reproducing the Python raytracer's geometric
intersection logic, structured for future rayon parallelism and PyO3
bindings. No Python/FFI dependencies — builds as a plain Rust crate
with only glam for vector math.

Geometry primitives (each implementing Send + Sync Intersectable trait):
  - Sphere (quadratic formula, t > 0.01 epsilon)
  - Infinite plane (fequal 1e-6 parallel check, t < 0 rejection)
  - Checkered plane (round/mod-2 XOR tiling, rem_euclid for negatives)
  - Triangle (Möller–Trumbore, 1e-6 epsilon, t > 0.01, back-face flip)
  - Triangle mesh with single-AABB slab-method acceleration

All epsilons, the back-face normal flip rule, the checkered tiling
logic, and the AABB slab method match the Python source exactly.

Scene-level trace_ray returns closest Hit across all objects.

30 unit tests covering hits, misses, edge cases (tangent, parallel,
back-face, vertex/edge hits), AABB rejection verification, and
closest-hit-among-multiple-candidates for meshes and scenes.
